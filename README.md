# Sin's Portfolio — GitHub Pages Ready

Portofolio interaktif milik **Sindara Sekar Prameswari** dengan animasi modern dan efek suara (Web Audio API SFX) tanpa dependensi eksternal.

## Struktur File
- `index.html` — Struktur halaman utama
- `style.css` — Tema dark-tech, animasi scroll reveal, 3D tilt, preloader, dan responsif mobile
- `script.js` — Data portofolio (`DATA`), animasi typing, particle network, dan engine sound effect (`SFX`)

## Cara Upload ke GitHub Pages
1. Ekstrak file `.zip` ini.
2. Masukkan semua file gambar kamu (`pfp.png`, `about.png`, `metopen.png`, `smartsolar.png`, dll.) ke dalam folder yang sama dengan `index.html`.
3. Upload seluruh isi folder ke repository GitHub kamu.
4. Buka **Settings → Pages → Branch: `main` / `/ (root)` → Save**.
5. Tunggu 1–2 menit hingga link GitHub Pages aktif.

## Catatan Sound Effects
- Browser modern mewajibkan satu klik/interaksi pertama dari pengguna sebelum audio aktif.
- Tersedia tombol **🔊 SFX / 🔇** di navbar untuk menyalakan atau mematikan efek suara kapan saja.
